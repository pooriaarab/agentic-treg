# agentic-treg

Run `npx agentic-treg search "search results"`.
Inspect a result with `npx agentic-treg get <id>`.
Preview with `npx agentic-treg call <id> --params '{}'`.
Add `--live` only when execution is authorized.
Run `npx agentic-treg doctor` for diagnostics.
Report failures and truncation explicitly.
Never expose token values.
